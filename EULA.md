## Your files

The Extension reads your Markdown files and their images, and writes only:

- The PDF files you export (an existing PDF of the same name is replaced)
- Your settings files, when you save a design in Studio or **Design pages**
- Logo images you add, copied into an `assets` folder beside the settings file
- Other editors' configuration files, only for the setup steps you click in Studio when it is
  opened in your web browser

It does not change your Markdown files. Still, keep backups or use version control (such as Git)
for files you care about, and check a PDF before you rely on it or share it. The Licensor is not
liable for files replaced, lost or damaged while using the Extension.
