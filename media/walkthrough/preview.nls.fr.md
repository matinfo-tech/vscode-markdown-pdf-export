# Voir le vrai PDF pendant que vous écrivez

Ouvrez un fichier Markdown et utilisez le bouton d'aperçu en haut à droite de l'éditeur.

Le panneau montre le PDF lui-même, avec son en-tête, son pied de page et ses numéros de page. Il est redessiné un instant après que vous arrêtez de taper, enregistré ou non, et il suit le fichier Markdown que vous mettez au premier plan.

Le HTML brut écarté par sécurité et les diagrammes qui n'ont pas pu être dessinés apparaissent dans le panneau Problèmes, sur la ligne qui les a causés.

[Ouvrir l'aperçu PDF](command:markdownPdfExport.openPreview)
