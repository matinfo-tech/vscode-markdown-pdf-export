# Exporter

Appuyez sur **Cmd+K Cmd+E** (Ctrl+K Ctrl+E sous Windows et Linux), ou utilisez le bouton PDF dans la barre de titre de l'éditeur, ou faites un clic droit sur un fichier Markdown dans l'éditeur ou l'Explorateur. Plusieurs fichiers sélectionnés dans l'Explorateur s'exportent ensemble.

Le PDF est écrit à côté du fichier Markdown.
